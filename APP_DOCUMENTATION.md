# MONOKERNEL - Retro Terminal Music Station

MONOKERNEL is a high-fidelity, retro-themed music player built with a focus on cyberpunk aesthetics, terminal-style interfaces, and high-performance audio playback. It blends the nostalgia of 80s computing with modern web technologies.

## 🚀 Tech Stack

### Core Frameworks
*   **Electron**: Cross-platform desktop framework combining Node.js and Chromium.
*   **React (v18)**: Frontend library for building the reactive user interface.
*   **Vite**: Next-generation frontend tooling for ultra-fast development and building.

### Styling & Visuals
*   **Tailwind CSS**: Utility-first CSS framework for layout and basic styling.
*   **Vanilla CSS (Custom)**: Used for high-fidelity CRT effects, scanlines, neon glows, and custom scrollbars.
*   **Material Symbols**: Used for the minimalist, icon-based navigation.

### Backend & Audio Engine
*   **Node.js (Main Process)**: Handles file system indexing and window management.
*   **music-metadata**: Extracts ID3 tags, album art, and technical audio data from local files.
*   **Web Audio API**: Powers the real-time frequency visualizers and audio analysis.
*   **Custom `media://` Protocol**: A secure internal protocol used to stream local audio files bypass CSP restrictions.

## 🛠 Features & Functionality

### 1. Library Management
*   **Local Directory Scanning**: Deep-scans local folders for audio files (`.mp3`, `.flac`, `.wav`, etc.).
*   **Metadata Extraction**: Automatically groups tracks into albums based on ID3 tags.
*   **Album Art Support**: Displays high-resolution album art extracted directly from the audio binaries.

### 2. High-Tech Playback Experience
*   **Real-time Frequency Analysis**: 3D and 2D spectrum visualizers that react to audio frequencies.
*   **Interactive Seek & Volume**: Custom-built, draggable sliders with theme-aware neon glows.
*   **Dynamic Queue System**: Manage your upcoming tracks with a sliding side-drawer interface.
*   **Playlist Creation**: Build custom collections with user-uploaded cover art.

### 3. Retro Aesthetic Engine
*   **Global Theme System**: 10+ pre-built high-contrast color themes (Phosphor Green, Cyber Cyan, Dracula Purple, etc.).
*   **CRT Simulation**: 
    *   **Flat Scanlines**: Horizontal interlacing for that vintage monitor texture.
    *   **Text Bloom**: A neon-style "glowing" effect on all text characters.
    *   **Neon Borders**: Vibrant outer glows on interactive elements.
*   **ASCII Art Processing**: Real-time generation of ASCII-style album covers for a raw, terminal look.

## 📂 Architecture

### Frontend (Renderer Process)
*   **Context API**: 
    *   `LibraryContext`: Manages the indexed tracks, albums, playlists, and theme state.
    *   `AudioContext`: Manages the playback engine, audio node graph, and analyser.
*   **Routing**: `react-router-dom` handles navigation between the Library, Albums, Search, and Settings views.

### Backend (Main Process)
*   **IPC Communication**: Uses `ipcMain.handle` and `ipcRenderer.invoke` for secure, asynchronous communication between the UI and the Node.js environment.
*   **File System Access**: Uses Node's `fs/promises` for efficient directory walking and file reading.
*   **Security**: Implements Context Isolation and custom protocol registration to keep the application secure while maintaining access to local media.
